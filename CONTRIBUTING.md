# Contributing
Dear programmers! Your improvements and changes are more than welcome! 

Feel free to pull request! That's why it's open source!

## IMPORTANT NOTE!
Changes only inside main.py!

Not in index.html, player_vs_computer.apk, and player_vs_computer.taz.gz. 

Because it's a Python-Pygame game by Pygbag - index.html, player_vs_computer.apk, and player_vs_computer.taz.gz MUST be created using Pygbag.

### Changes that are very welcome:
- Bug fixes
- Better compatibility
- Small changes that don't have a general impact on the **main** gameplay
- Little changes in the gameplay (that must be accepted by the entire REParadoxy)

### Changes that won't be accept:
- Undo/redo features
- Changes of the current assets: images, the music or the sounds
